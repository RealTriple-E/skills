# Elyazer Skills — Claude Code Plugin

Install with:

```bash
claude plugins install elyazer-skills
```

Or from inside a session:

```
/plugin install elyazer-skills
```

Available commands:
- `/duckswarm` — multi-model debate and consensus orchestration via Duck.ai
- `/unvibecode-ui` — frontend UI audit and unvibecoding
- `/x-growth-intelligence` — X/Twitter growth strategy, content, and publishing
