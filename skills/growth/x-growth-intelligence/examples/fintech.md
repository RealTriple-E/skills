# Example — Fintech Product Launch

**Objective:** Trust-sensitive launch of a new savings product.  
**Audience:** SMEs and entrepreneurs (example geography: Zambia + broader Africa).  
**Autonomous mode:** Approval only (never Autonomous for trust-sensitive claims).  
**Execution:** browser-session-persistent.  
**Crisis Mode:** pre-armed.

## Approach

1. Brand Guardrails block absolute return claims and unapproved pricing language.  
2. Campaign phases: Problem awareness → Education on saving friction → Solution introduction → Proof/trust → Launch → Questions → Conversion → Retention.  
3. Each phase linked on Kanban so later phases wait for earlier Published status.  
4. Voice DNA: professional, clear, trustworthy, low provocation.  
5. Algorithm note: optimize for dwell and thoughtful replies; follower count is not a direct ranking lever.  
6. Any spike in report-weighted negative signals → halt remaining sequence and surface for human review.

## Guardrail Examples

- NEVER: “Guaranteed returns”  
- PREFERRED: “Designed to help you build savings discipline”
