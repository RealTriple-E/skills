# Example — Personal Developer / Creator Account

**Objective:** Developer reputation and thoughtful audience growth.  
**Audience:** Working developers, open-source contributors, technical decision makers.  
**Autonomous mode:** Assisted (after owner has observed correct behavior for several weeks).  
**Execution:** browser-session-persistent.

## Approach

1. Shift away from corporate marketing language.  
2. Content pillars: technical insights, tutorials, opinions, build-in-public, useful discoveries, high-quality replies.  
3. Reply Intelligence prioritizes adding original value over volume.  
4. Voice DNA: high technical depth, moderate humor, high directness, low emoji, short-to-medium sentences.  
5. Trend filter is strict — only engage when the account can add credible, original perspective.  
6. Experiments: contrarian vs informational hooks on the same technical topic.

## Sample Output Style

Concrete observation → short explanation → one clear implication or question.  
No “In today’s fast-paced world” openings.
