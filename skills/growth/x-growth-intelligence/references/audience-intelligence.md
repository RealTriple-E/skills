# Audience Intelligence Engine

Author: Elyazer Emmanuel

## Purpose

Build a living model of “who are we trying to reach?” so the same topic can be written differently for different segments.

## Audience Model Dimensions

```
Audience
├── Demographics
├── Geography (timezone, country, region, local holidays, cultural context)
├── Profession / Role
├── Interests
├── Pain points
├── Goals / Desired outcomes
├── Objections / Barriers
├── Language & vocabulary level
├── Knowledge level (beginner → expert)
├── Content preferences (format, length, tone, media)
└── Buying / decision stage (if commercial)
```

## Usage Rules

- Refresh or refine the model from Account Profile, recent engagement, and any available analytics.
- Never assume a global default audience.
- Geographic Intelligence drives timing: post when the intended audience is active, not on a generic UTC schedule.
- Language: write in the audience’s language; localize idioms rather than translate literally; produce bilingual content only when the profile explicitly calls for it.

## Output

A concise audience brief that the Writing Engine and Content-Market Fit Engine can consume. Keep it short enough to stay in context; expand only the dimensions that affect the current piece.
